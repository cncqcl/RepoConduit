# 安全、安装与运行合约 v0.2

## 1. 默认运行边界

单个使用者、本地信任域、多个独立工作区；不作为公开多租户SaaS。源码域、协作域、执行域分开。外部不获任意源写和命令能力，授权范围和实际sandbox均检查。

默认进程监听 loopback 或私有 IPC；远程 ChatGPT 必须使用已授权的受支持安全隧道/HTTPS入口，不能把“本地服务启动”当作外部已可达。管理接口与外部MCP入口分开；local不等于已认证，需要 OS-owned IPC 或独立本地凭据/来源验证。

外部入口选择一个经实测有效的 OAuth/安全隧道方案，角色映射到 principal/audience/grant。默认不开公网、不创建付费隧道、不把令牌放URL或项目目录；能力不足时明确引导可信本地授权。

## 2. Local Investigator 不是研发子代理

研发 `.codex/agents/*.toml` 用于写本项目，不可直接作为用户仓库调查隔离。独立investigator启动时使用专用 CODEX_HOME/配置、清理的环境、明确源码视图与scratch，禁用无关MCP/插件/读取目录。只允许必要的模型服务凭据及请求，不把主会话所有文件、浏览器cookie和agent历史传入。

只读sandbox并不必然禁止读取用户其他目录；必须用实际文件访问负向测试证明范围。运行时无法做强范围限制时，以隔离工作副本+OS/容器等方式实现，仍不满足就标该能力unverified/unsupported。prompt中的“不要越权”只能辅助。

验证profile与静态profile分开；tests/build可能执行不可信代码、写缓存、访问网络。所有例外经过本地授权和隔离环境，不以“只是测试”放行。

## 3. 文件与下载

文件名、ZIP结构、模型文本和URL均不信任。下载验证包括允许来源、重定向每一跳、DNS/实际连接地址、TLS host绑定、响应总量/超时、Content-Type辅助检查；拒绝私网、loopback、link-local与未授权目标。不能只检查初始URL后自动跟随。

平台file_id不是任意公网链接；过期需要重新取得被授权的引用，不猜内部endpoint。临时URL与token只在适配器私有执行内存/受限存储使用，不写入可导出的manifest。

包内可包含AGENTS.md/SKILL.md/sh/patch作为研究成果，但保持待审数据，不放到会自动加载的宿主目录。主动内容默认不渲染；预览需要隔离和明确选择。解包路径及大小规则见接口合约。

## 4. 授权与披露

一个参与者被允许读代码，不代表可以发给另一个模型。原始代码、摘要、错误路径和调查结果都有接收者范围。操作开始和披露结果时都检查grant；撤销中止新dispatch，清理或隔离未披露结果。已经传到外部provider的数据无法保证召回，应提前提示并记录。

网页普通消息不能扩大权限，即使内容声称“我是用户已批准”。实际授权必须从可信本地管理界面/命令/宿主明确审批产生，并绑定操作和范围。预算含并发、时长、请求数、输出量；缺少真实usage则费用unknown。

## 5. 安装与更新

M06提供可重复安装、诊断、启动、停止、升级和卸载。安装为create-only或备份/冲突检查，不覆盖用户AGENTS/全局配置；不自动设置服务开机启动。用户明确选择常驻时才配置service manager，并提供撤销方式。

版本固定依赖lockfile及协议bindings；更新会话、工具schema或文件协议要失效相关能力证据，必要时重新连接/授权，但不能盲删不相关连接器。升级前检查在途exchange/attempt/bundle，无法安全drain则给出具体冲突，不杀死未知用户进程。

卸载移除的是本项目安装项；项目源码、已发布成果、用户聊天与证据默认保留。数据删除是独立明确操作，不承诺provider侧同步删除。

## 6. 运行与恢复

状态DB使用受限权限，日志脱敏。收到停止：拒绝新副作用操作、暂停发送/调查、标记未确认项、flush、关闭。恢复依据DB状态/原生IDs/对象hash重新对账，不根据进程是否在线推断任务是否完成。

不能adopt不属于本系统的任意线程和进程；自己的任务取消需确认整个相关进程树或原生turn已终止。没有确定证据保留recovery_required。调度使用epoch fencing，旧实例不能发布新结果。

## 7. 安全验收最低集合

路径穿越/大小写/链接/TOCTOU；cross-workspace和错误audience；读取已撤销结果；隐藏工具直调；调查请求混入shell/model/env；源注入请求凭据/网络/源码写；ZIP bomb/重复entry/设备文件；临时URL泄漏；unknown send重复副作用；stale worker提交；DB/FS发布崩溃；第三方成果冒充AGENTS自动加载。每类至少一个实际断言和回归测试，不能只写风险清单。
