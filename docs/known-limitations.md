# 已知限制

- **完整发布验收尚未通过。** 已有的离线检查和真实组件记录绑定各自的源码、包和环境，不能拼成同一版本的完整通过。验收条件和当前证据边界见[验收手册](ACCEPTANCE_AND_LIVE_RUNBOOK.md)与[验证状态](release-evidence.md)。
- **第二运行时尚未完成。** 当前优先 Codex 与 ChatGPT；Claude/GLM 后置，不能据此宣称完整的跨运行时验收通过。
- **本机连接需要运行。** 本机离线时网页无法通过它新读取本机材料、启动本地调查或向本机交付。网页既有聊天和已读资料是否可用取决于相应服务；不要假设离线结果会自动补投。
- **材料是有范围的冻结快照。** 已授权的 Git 跟踪文件、排除项和固定提交决定可读内容。新提交或工作区未提交修改不会自动进入旧课题；不同来源即使指向同一仓库也可能是不同提交。
- **讨论与实施分开。** 网页回复不等于已交付，交付不等于已经本地审查，也不等于授权修改代码。自动文件收取和 `manual_import` 是不同路线；手动导入原件不证明自动交付成功。
- **调查并非默认开放。** 本地调查需要有效的隔离、配置、权限和预算；工具可见或完成普通讨论不代表已获调查权限。
- **容量有限。** 以当前实现和安装的实际配置为准；容量不足时先检查现有材料与课题，不通过新开聊天绕过限制。
- **已知历史问题仍保留。** 曾观察到本地 tgz 安装的依赖锁漂移、部分运行失败和状态未知；归档或更换文档不改变这些结果。完整依赖许可审阅和统一版本验证仍需按实际结果完成。

当前操作和恢复方法见[操作说明](operations.md)；日常场景见[用户使用说明](user-guide/README.md)。
