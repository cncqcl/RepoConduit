# 能力观察与限制

本页汇总历史上有范围的观察，供理解产品和后续验收使用，不代表当前账号、客户端、进程或安装处于相同状态。原始诊断、失败、UNKNOWN 和证据按其原版本、环境与时间保留为私有资料，摘要见[验证状态](release-evidence.md)。

历史 WSL 诊断脚本及其测试使用 `fixture` 占位账户和示例路径。这些占位值不代表当前机器存在该账户或完成隔离资格；重新运行前须按实际环境配置并重新验证，旧环境的结果不得转作新环境通过。

| 历史观察 | 限制 |
| --- | --- |
| 安装 CLI/MCP 与离线包检查在特定版本上有记录 | 不证明当前源码或其他环境的安装和完整发布通过 |
| Codex 与 ChatGPT 的部分网页读取、调查、人工接管恢复和交付有组件记录 | 记录来自不同包和执行；不等于统一版本的完整 LIVE |
| 目录原件曾经由本地 `manual_import` 恢复 | 不证明平台自动原件交付或其他文件路线成功 |
| Windows readiness、权限与运行时隔离曾进行有界诊断 | readiness、测试替身和生产隔离是不同证据；旧版本结果不是当前环境资格 |
| 曾记录调用失败、超时、跳过及未知关闭 | 未知不推断为失败或成功，也不盲目重发或删除现场 |
| 第二运行时做过受限探测和离线验证 | 模拟与局部组件不等于真实第二运行时或完整中立性通过 |
| 曾观察本地 tgz 依赖锁漂移 | 需单独核实并解决；不是完整发布通过的证据 |

重新执行探测前，先查看实际版本的接口、已有授权和[验收手册](ACCEPTANCE_AND_LIVE_RUNBOOK.md)，只检查受影响范围。真实模型、真实人类操作和付费或公开服务不由本页自动授权。
