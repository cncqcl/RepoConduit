# GreetingDemo

这是 RepoConduit 入门手册的三文件教学项目，不含凭据和外部依赖。

## 已有行为

`greet(name)` 对字符串去掉首尾空格，然后返回 `Hello, NAME!`。
使用 Node.js 24.x 运行：

```powershell
node --test tests/greet.test.mjs
```

## 本次讨论

讨论如何处理空字符串、纯空白和非字符串输入，指出当前实现与测试的缺口。
先提交评审报告，不修改源码，也不自动运行本地调查模型。

现有两个正常输入测试用于确认起点；没有覆盖全部边界情况。
预期报告文件为 `review.md`，版本名 `review-v1`，至少包含证据路径、问题、建议和未确认项。

## 准备

把此文件夹放入你的教学目录；首次使用前，沿用你自己的 Git 身份初始化并提交这三个文件。
RepoConduit 的冻结材料读取来自 Git 提交，不自动包含未提交或未跟踪文件。
